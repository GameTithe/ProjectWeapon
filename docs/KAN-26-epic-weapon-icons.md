# KAN-26 영웅 무기 3종 픽셀 아이콘

`Assets/ProjectWeapon/Art/EpicWeaponIcons/`에 원본 32×32px 투명 Sprite Single을 둔다. 32 PPU와 Point 필터를 사용한다. 우하단 보라색 교차 표식이 영웅 등급을 표시한다. 원본은 `art-source/Export-EpicWeaponIcons.ps1`로 재생성하며 외부 이미지를 사용하지 않는다. [KAN-26](https://gametithe.atlassian.net/browse/KAN-26) · [KAN-21](https://gametithe.atlassian.net/browse/KAN-21) · [KAN-22](https://gametithe.atlassian.net/browse/KAN-22)

| 무기 | Sprite | 형태 |
| --- | --- | --- |
| 폭풍의 검 | `StormSword` | 넓은 바람 궤적을 두른 은보라 검날 |
| 심연의 낫 | `AbyssScythe` | 짙은 보라 자루와 날카로운 초승달 낫날 |
| 태양의 활 | `SolarBow` | 금빛 활대에 연결된 작은 태양 |

UI에서는 원본 종횡비를 유지하고 24×24px 이상으로 표시한다.

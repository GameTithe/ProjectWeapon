# KAN-108 저주받은 숲 3구역 적과 상자 배치

`Assets/Scenes/Zone3Greybox/Zone3Greybox.unity`를 열고 Play한다. WASD로 이동하고 Space로 회피한다. 사거리 안의 적은 낡은 검으로 자동 공격한다. E는 상자나 귀환진에 사용한다. 기존 32 PPU 검증용 픽셀 스프라이트를 숲의 갈색 근접 적과 차가운 청색 원거리 적으로 구분했다. [KAN-108](https://gametithe.atlassian.net/browse/KAN-108) · [KAN-104](https://gametithe.atlassian.net/browse/KAN-104) · [KAN-21](https://gametithe.atlassian.net/browse/KAN-21)

| 대상 | 월드 좌표 | 반응 |
| --- | --- | --- |
| 공터 근접 적 | (6.5, 6.5) | 시야 안의 플레이어에게 접근하고 주황 부채꼴로 예고한다. |
| 가시덤불 보초 | (9.5, 4.5) | 시야가 열린 중앙 길에 붉은 직선 공격을 예고한다. |
| 선택 상자 | (7.5, 4.5) | 범위 0.8유닛에서 E로 한 번 열고 실제 월드 실물 하나를 떨어뜨린다. |
| 기존 귀환진 | (14.5, 2.5) | 반경 0.75유닛. 정지 상태에서 E로 시작하고 3초간 유지한다. |

1. 시작점에서 동쪽으로 이동해 벽에 닿으면 x≈3.5를 맞춘다. 상자를 선택하면 y≈6.5에서 동쪽으로 들어가 근접 적과 싸운다.
2. x≈7.5까지 동쪽으로 가서 y≈4.5로 내려가면 상자와 보초가 보인다. E로 상자를 열고 떨어진 실물 위로 걸어가 줍는다. 가까이에서 원거리 적을 처치할 수 있다.
3. x≈8.5에서 남쪽 통로 y≈1.5로 내려가 동쪽 끝까지 이동한다. x≈14.5에서 북쪽으로 파란 귀환진에 접근해 E를 누른다. 상자를 지나치려면 처음부터 x≈3.5를 따라 남쪽으로 내려가 같은 귀환 경로를 잇는다.

구역 설정은 `PrototypeZoneCatalog`의 권장 3등급, 제한 720초, 일반 상자 보상 등급 2등급 45%·3등급 45%·4등급 10%를 읽는다. 이 씬의 기존 고정 상자 프리팹은 경로 검증용 1등급 나무 창 한 개로 동작한다. 등급 확률은 배치 데이터 참조용이며, 배치 검증은 보상 추첨과 분리된다. 획득한 실물은 검증 런의 가방에서 볼 수 있다. [KAN-192](https://gametithe.atlassian.net/browse/KAN-192)

`Zone3ForestTrial`은 기존 2D 탐지·예고, 낡은 검 타격, 플레이어 피해, 물리 픽업과 귀환 계약을 사용한다. 좁은 길에서 근접 적의 원형 충돌 범위가 북쪽 장벽에 걸리지 않도록 씬 인스턴스의 Y 오프셋만 0.18로 맞췄다. 기존 타일맵과 북동쪽 갈래는 유지했다. [KAN-106](https://gametithe.atlassian.net/browse/KAN-106)

## 자동 재현

```powershell
unity test . --mode PlayMode --filter ProjectWeapon.Zone3Greybox.Tests --output "$env:TEMP/KAN-108-forest-targeted.xml" --timeout 180
```

실제 씬에서 키보드 입력과 2D 물리 시뮬레이션을 사용한다. 타일에 막힌 뒤 남쪽 직행과 두 적·상자를 건드리지 않은 귀환, 중앙 갈래의 예고·피해·적 처치와 상자 중복 열기 거절, 같은 실물 ID의 물리 획득을 검사한다. 귀환 범위 밖 시작 거부, 정확한 경계와 3초 채널 완료, 완료와 720초 마감이 동시에 도착한 경우의 시간 초과 및 종료 후 상자 차단도 함께 확인한다.

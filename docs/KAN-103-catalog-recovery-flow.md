# KAN-103 성공 귀환 도감 회수

- [KAN-103](https://gametithe.atlassian.net/browse/KAN-103) · [KAN-92](https://gametithe.atlassian.net/browse/KAN-92) · [KAN-96](https://gametithe.atlassian.net/browse/KAN-96)
- 기존 `RunSettlementCoordinator`가 성공 귀환에서 실제로 보유한 개인 무기의 원형을 기록하고, 정산 결과와 같은 저장 커밋에서 확정한다. 인벤토리와 도감 저장 코드는 유지했다.
- EditMode에서 코인 뽑기와 실제 보유 무기의 출격, 탐험 가방 교체, 귀환 종료, 원자 저장과 저장소 재개를 통합 검증한다. 가방 교체 검증은 1칸 용량으로 구성하고 뽑기는 결정적인 테스트 테이블을 주입한다.
- 귀환 전 뽑기와 출격만으로는 회수 상태가 생기지 않는다. 성공 귀환 당시 보유한 무기만 회수에 등록되고, 대여품이나 가방 교체로 빠진 무기 및 사망·시간 초과 시 들고 있던 무기는 제외된다.
- 회수한 무기를 다음 탐험에서 잃어도 이전 도감 상태가 유지된다. 동일 귀환 영수증 10회 재호출 후에도 저장 버전과 회수 종수가 유지된다.

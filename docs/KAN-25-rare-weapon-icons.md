# KAN-25 희귀 무기 5종 픽셀 아이콘

`Assets/ProjectWeapon/Art/RareWeaponIcons/`에 원본 32×32px 투명 Sprite Single을 둔다. 32 PPU와 Point 필터를 사용한다. 우하단의 파란 빈 마름모가 희귀 등급을 표시한다. 원본 스프라이트는 `art-source/Export-RareWeaponIcons.ps1`로 재생성한다. [KAN-25](https://gametithe.atlassian.net/browse/KAN-25) · [KAN-21](https://gametithe.atlassian.net/browse/KAN-21) · [KAN-22](https://gametithe.atlassian.net/browse/KAN-22)

| 무기 | Sprite | 형태 |
| --- | --- | --- |
| 서리창 | `FrostSpear` | 긴 자루 끝의 푸른 얼음 결정 |
| 번개검 | `LightningSword` | 지그재그 은보라 검날 |
| 폭발궁 | `BlastBow` | 휘어진 활대와 밝은 폭발 표식 |
| 그림자 단검 | `ShadowDagger` | 짧은 보라 단검과 초승달 잔상 |
| 용암 도끼 | `MagmaAxe` | 넓은 검은 도끼 날과 주황색 용암 균열 |

UI에서는 원본 종횡비를 유지하고 24×24px 이상으로 표시한다.

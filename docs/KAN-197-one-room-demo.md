# KAN-197 던전 한 방 플레이 데모

[Jira KAN-197](https://gametithe.atlassian.net/browse/KAN-197)

Unity 6000.6.9f1에서 `Assets/Scenes/OneRoomDemo/OneRoomDemo.unity`를 열고 Play를 누른다. WASD, 방향키, 화면 왼쪽 패드로 이동한다. 입력을 놓으면 바라보던 방향으로 대기한다. 전리품과 경비병을 모두 다시 확인하려면 Play를 종료한 뒤 다시 실행한다.

## 확인 순서

1. 시작점에서 남쪽으로 내려가 파란 전리품을 왼쪽부터 세 개 획득한다. 하단 가방에 단검, 사냥 활, 철퇴가 차례로 추가된다.
2. 네 번째 전리품인 나무 창에 닿으면 비교 화면이 열린다. 이동 입력을 유지해도 캐릭터가 움직이지 않으며, 경비병 행동도 일시 정지한다.
3. 취소하면 가방과 바닥의 나무 창이 유지된다. 범위에서 나갔다 들어와 비교를 다시 열고, 소지품 하나를 선택한 뒤 교체한다. 고른 슬롯은 나무 창으로 바뀌고 교체된 무기는 남쪽 통로의 빈자리에 떨어진다.
4. 동쪽 경비병에게 다가가면 경비병이 추적을 시작한다. 발밑에서 공격 예고 부채꼴이 뜨면, 범위 안에 남아 피격에 따른 체력 감소와 붉은 플래시를 확인한다. 범위를 나가면 빗나간다.
5. 낡은 검 범위에 들어가면 자동으로 베기 시작한다. 네 방향 전투 스프라이트와 손에 든 낡은 검이 함께 전환된다. 세 번째 셀에 도달할 때 실제 베기 피해가 적용되며, 경비병은 세 번 명중하면 쓰러지고 접촉이 풀린다.

## 씬 구성

- 한 방의 이동·전투·전리품을 기존 이동, 자동 공격, 근접 경비병, 인벤토리와 획득 컴포넌트로 연결했다. 장착 상태와 가방은 Play마다 새로 만든다.
- 베기는 셀당 65ms이며, 시작 130ms 후 세 번째 셀에서 대상 위치를 갱신해 기존 판정으로 피해를 계산한다. 경비병의 공격 예고는 실제 방향·각도·반경을 읽는다.
- KAN-28 유랑 검사 대기·이동 스프라이트와 기존 방향별 베기를 사용한다. 경비병은 제공된 16비트 던전 컨셉의 어두운 금속 갑옷과 붉은 장식, 전리품은 청색 강조를 참고해 씬 전용 픽셀 스프라이트로 만들었다. 방 바닥은 KAN-18의 32 PPU 타일을 재사용했다.
- 씬 전용 한글 SDF 아틀라스는 Noto Sans CJK KR Regular에서 이 씬과 획득 패널에 필요한 글자를 추출했다. 기본 TMP 설정과 셰이더를 저장소에서 함께 읽으므로 설치된 시스템 글꼴이 필요 없다. [Noto 원본](https://github.com/notofonts/noto-cjk/blob/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/OTF/Korean/NotoSansCJKkr-Regular.otf), [SIL OFL](../Assets/Scenes/OneRoomDemo/DemoHangul-OFL.txt)
- 출격·귀환·정산·재입장은 KAN-193의 통합 범위다. 이 씬은 Play 테스트와 한 방 확인용이다.

## 자동 확인

Unity Test Runner의 PlayMode에서 `ProjectWeapon.OneRoomDemo.PlayMode.Tests`의 테스트를 실행한다. 씬을 직접 로드해 이동 해제, 비교 중 이동 차단, 취소·교체 후 인벤토리와 월드 드랍, 경비병 예고·실제 피격, 베기 피해 프레임을 확인한다.

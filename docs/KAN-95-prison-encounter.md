# KAN-95 지하 감옥 2구역 전투와 상자

Unity에서 `Assets/Scenes/Zone2Greybox/Zone2Greybox.unity`를 열고 Play한다. 기존 KAN-100 맵과 귀환진을 사용한 검증 씬이다. WASD로 이동하고, 범위 안의 적은 낡은 검으로 자동 공격한다. Space는 회피, E는 범위 안의 상자 또는 귀환진에 사용한다. 화면의 주황 부채꼴은 근접 경비 공격, 붉은 직사각형은 원거리 보초 공격 예고다. [KAN-95](https://gametithe.atlassian.net/browse/KAN-95) · [KAN-100](https://gametithe.atlassian.net/browse/KAN-100) · [KAN-91](https://gametithe.atlassian.net/browse/KAN-91)

| 배치 | 월드 좌표 | 역할 |
| --- | --- | --- |
| 근접 경비 | (2.5, 7.5) | 북서 복도에서 접근한다. 기존 경비 설정과 Rigidbody2D를 사용한다. |
| 원거리 보초 | (9.5, 1.5) | 남쪽 주 통로를 내려다본다. 기존 직선 공격 설정을 사용한다. |
| 검증용 고정 상자 | (1.5, 3.5) | 주 경로에서 서쪽으로 꺾는 선택 갈래다. |
| 귀환진 | (15.5, 1.5) | 기존 1유닛 반경. 정지 상태에서 3초 채널링한다. |

1. 시작점에서 오른쪽으로 이동하면 첫 감방 벽에 막힌다. 북서쪽의 근접 경비가 가까워지면 자동 공격하고, x=4.5의 통로를 남쪽으로 내려간다.
2. 직행하려면 y=4.5에서 x=2.5로 이동해 남쪽 복도로 잇는다. 상자를 열려면 x=1.5로 한 칸 더 돌아 y=3.5에서 E를 누른다. 오른쪽의 떨어진 무기에 걸어가 실제 충돌로 줍는다.
3. 남쪽 통로를 오른쪽으로 걸어 원거리 보초를 지나고, 파란 귀환진에 닿기 전에는 E로 채널을 시작할 수 없다. 범위 안에서 정지한 뒤 E를 누르면 3초에 귀환한다. 이동·회피 입력이나 유효 피해는 진행 중 채널을 취소한다.

일반 상자 보상 등급 가안은 `PrototypeZoneCatalog`의 구역 2에 있는 1등급 45%, 2등급 45%, 3등급 10%를 읽는다. 배치에 사용한 기존 고정 상자 프리팹은 경로 재현용 1등급 나무 창을 한 번 떨어뜨린다. 씬에서 가안 확률을 추첨에 사용하지 않는다. 줍는 무기는 이 씬의 임시 가방에 남으며, 프로필 저장이나 정산을 호출하지 않는다.

## 자동 재현

```powershell
unity test . --mode PlayMode --filter ProjectWeapon.Zone2Greybox.Tests.Zone2GreyboxTests --output "$env:TEMP/KAN-95-prison.xml"
```

PlayMode에서 실제 2D 물리 씬의 키보드 입력, 벽 충돌, 두 적과 플레이어의 체력, 한 번만 열린 상자와 같은 실물 ID의 충돌 획득을 검사한다. 범위 밖 시작 거부, 3초 직전 진행 중과 정확한 완료, 제한 600초와 완료가 겹친 때 시간 초과, 종료 뒤 상자 차단도 확인한다.

# KAN-185 탐험 상단 지도

[Jira KAN-185](https://gametithe.atlassian.net/browse/KAN-185)

## 연결

1. 기존 던전 Canvas 아래에 화면을 채우는 RectTransform을 두고 `RunMapPanel`을 붙인다. Canvas에는 GraphicRaycaster와 EventSystem이 필요하다. 오른쪽 상단에 지도 버튼이 나타난다.
2. `Initialize(run, catalog, font, readMap)`에 현재 런 상태, 구역 카탈로그, 한글 TMP 폰트, 지도 상태 조회 함수를 넘긴다. 조회 함수는 현재 런 ID와 구역 ID로 `RunMapData`를 생성한다.
3. 지도 데이터에는 방 ID와 지도용 정수 격자 셀, 방문한 방 ID, 확인된 연결의 양 끝 방 ID, 현재 방 ID를 넣는다. 현재 방은 방문 목록에도 있어야 표시된다. 새 방이나 연결을 확인하면 `Refresh()`를 호출한다. 데이터가 아직 없으면 null을 반환한다.
4. 호스트는 지도의 `OwnsGameplayInput`이 참인 동안 게임 조작을 막는다. UI 포인터 판별을 입력 필터에도 연결해 버튼의 누르기·놓기가 월드에 전달되지 않게 한다. 기존에 잡힌 조이스틱이 있으면 해제하고, UI에서 시작된 포인터는 손을 뗄 때까지 게임 조작으로 넘기지 않는다. 탐험 시계와 적 행동은 기존 루프에서 계속 처리한다.

## 재현

- 탐험 중 오른쪽 상단 지도 버튼을 누른다. 현재 구역의 번호·이름과 방문한 방, 확인한 연결, 현재 방 표식이 보인다. 데이터가 준비되지 않은 경우 구역 정보와 안내 문구가 나타난다. 닫기를 누르면 게임 화면으로 돌아온다.
- 여러 방 중 일부를 방문한다. 미방문 방과 그 방으로 이어지는 연결은 숨긴다. 두 방에 모두 방문했더라도 연결 데이터가 확인되기 전에는 선이 보이지 않는다. 현재 위치는 방 표식으로만 표시한다.
- 지도를 열어 둔 채 제한 시간을 지나면 지도와 버튼이 닫힌다. 다음 런에서는 새 구역 정보를 표시하며, 이전 런·구역의 지도 데이터를 적용하지 않는다.

Unity Test Runner의 EditMode에서 `ProjectWeapon.RunMapUI.Tests`를 실행한다. 실제 런·구역 카탈로그를 연결해 방문 범위, 구역과 런 불일치, 한 방 지도, 데이터 누락, 종료와 다음 런을 검증한다. CanvasRenderer에 방문 방·확인된 연결·현재 방 표식의 메시가 생성되는지도 확인한다.

# KAN-69 가중치 무기 추첨

`WeightedWeaponDraw`에 등급별 가중치, 원형 ID 목록, 원형 ID와 등급을 연결한 카탈로그를 전달한다. 가중치와 원형 목록은 1등급부터 5등급까지 같은 순서로 제공한다. 원형 목록에는 각 등급의 5·5·5·3·3개 항목이 필요하다. 추첨기는 가중치와 원형 목록을 검증해서 복사하며, 카탈로그의 값은 검증에 사용한다. [KAN-69](https://gametithe.atlassian.net/browse/KAN-69) · [KAN-187](https://gametithe.atlassian.net/browse/KAN-187)

## 가중치와 난수 계약

가중치는 KAN-20과 같은 정수 bp 단위이며 합은 10,000이다. `DraftGradeWeightsBasisPoints`는 **50·30·15·4·1%** 가안인 5,000·3,000·1,500·400·100bp를 제공한다. 추첨을 구성할 때 이 가안이나 별도 설정을 명시적으로 넘긴다. 승인된 확률은 후속 설정에서 관리한다. [KAN-20](https://gametithe.atlassian.net/browse/KAN-20)

1. 첫 번째 난수는 0 이상 10,000 미만의 균등 정수다. 가안에서 1~5등급 구간은 각각 0~4,999, 5,000~7,999, 8,000~9,499, 9,500~9,899, 9,900~9,999다.
2. 두 번째 난수는 0 이상 선택된 등급 원형 개수 미만의 균등 정수다. 각 등급의 원형 ID를 서수 순서로 정렬해 같은 입력과 난수에서 같은 원형을 선택한다.
3. 결과는 선택한 등급과 원형 ID다. 두 단계에서 정수 범위를 사용하고 표시용 반올림 확률은 입력으로 받지 않는다. 원형의 화면 표시 확률은 등급 확률을 해당 등급의 개수로 나눠 계산할 수 있다.

원형 ID 누락·중복·카탈로그 등급 불일치, 원형 개수 불일치, 가중치 합계 오류는 테이블 구성에서 검출한다. 난수 공급자가 범위를 벗어난 값을 반환하면 즉시 실패한다. 광고·코인 흐름은 같은 추첨기를 호출하고 실물 발급, 결제, UI와 거래 재시도 기록을 각자의 경계에서 처리한다. 이미 결과가 기록된 거래의 재시도는 기록된 원형 ID를 사용한다. [KAN-19](https://gametithe.atlassian.net/browse/KAN-19) · [KAN-63](https://gametithe.atlassian.net/browse/KAN-63)

## 검증 재현

```powershell
unity test . --mode EditMode --filter ProjectWeapon.WeaponDraw.Tests.WeightedWeaponDrawTests --output "$env:TEMP/KAN-69-results.xml"
```

| 입력 | 기대 결과 |
| --- | --- |
| 등급 난수 4,999와 5,000 | 각각 1등급 마지막과 2등급 첫 구간에 속한다. |
| 등급 난수 9,900, 원형 난수 0·1·2 | 5등급의 세 원형이 각각 정확히 한 번 선택된다. 원형 난수 3은 범위 오류다. |
| 등급 난수 0~9,999 전체 | 등급 선택 횟수는 5,000·3,000·1,500·400·100회다. |
| 같은 등급 목록의 입력 순서를 뒤집음 | 같은 난수에서 같은 원형 ID를 선택한다. |
| 9,999/10,001bp 합계, 누락·중복 또는 잘못 분류한 원형 | 추첨 전에 오류를 반환한다. |

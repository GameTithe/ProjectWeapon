# KAN-89 구역 타이머와 0초 귀환 경계

- [Jira KAN-89](https://gametithe.atlassian.net/browse/KAN-89)
- 구역에 출격할 때 `ZoneRunCountdown.TryStartRun`이 검증된 `ZoneCatalog`의 구역 제한시간을 `RunState`의 마감 시각에 반영한다.
- 탐험 루프는 사망, 귀환 취소 등 해당 프레임의 관찰값을 모아 `ZoneRunCountdown.ProcessFrame`을 한 번 호출한다. 관찰값이 없는 프레임도 빈 배열을 전달한다. 이 경로가 귀환 채널을 호출하면 `RunState`가 같은 시계 표본에서 예정된 귀환 완료와 마감 시각을 비교한다.
- HUD는 동일한 단조 시계에서 읽은 시각을 `Sample`에 전달한다. 출격 중 표시값은 구역 제한시간에서 0초까지 내려간다. 결과가 확정되면 결과 시점의 남은 시간으로 유지하고 마을로 돌아오면 표시값을 비운다.

## 재현

Unity Test Runner의 EditMode에서 `ZoneRunCountdownTests`를 실행한다. 직렬화된 프로토타입 구역 카탈로그의 1구역 480초와 5구역 900초를 사용한다.

| 마감 경계 입력 | 확정 결과 |
| --- | --- |
| 귀환 완료가 마감보다 1틱 빠르고 관찰 프레임은 마감 후에 도착 | 귀환 성공 |
| 귀환 완료가 마감과 같은 틱 | 시간 초과 |
| 귀환 완료가 마감보다 1틱 늦음 | 시간 초과 |
| 마감 직전 같은 틱에 귀환 완료와 사망을 수집 | 사망 |
| 마감 직전 같은 틱에 귀환 완료와 취소를 수집하고 마감 후 처리 | 시간 초과 |
| 마감 시각에 빈 프레임 처리 | 시간 초과 |

같은 결과 이후 프레임을 반복해도 확정 이벤트는 한 번 발생하고 당시의 남은 시간이 유지된다.

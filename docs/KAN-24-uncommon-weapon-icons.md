# KAN-24 고급 무기 5종 픽셀 아이콘

`Assets/ProjectWeapon/Art/UncommonWeaponIcons/`의 원본 32×32px Sprite Single은 32 PPU와 Point 필터를 사용한다. 우하단 초록 꺾쇠는 고급 등급을 알린다. `art-source/Export-UncommonWeaponIcons.ps1`로 재생성한다. 원본은 외부 이미지에 의존하지 않는다. [KAN-24](https://gametithe.atlassian.net/browse/KAN-24) · [KAN-21](https://gametithe.atlassian.net/browse/KAN-21) · [KAN-22](https://gametithe.atlassian.net/browse/KAN-22)

| 무기 | Sprite | 형태 |
| --- | --- | --- |
| 화염검 | `FlameSword` | 주황 불꽃이 위로 휘감기는 검날 |
| 강철창 | `SteelSpear` | 긴 푸른 강철 자루와 삼각 창날 |
| 연사궁 | `RepeaterBow` | 작은 금속 장식과 나란한 밝은 시위 |
| 전투도끼 | `BattleAxe` | 넓은 비대칭 도끼 날과 황동 결합부 |
| 쌍검 | `TwinSwords` | 서로 교차하는 두 개의 검과 가드 |

UI에서 원본 종횡비를 유지하고 24×24px 이상으로 표시한다.

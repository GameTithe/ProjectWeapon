# KAN-186 귀환 정산 결과 화면

[Jira KAN-186](https://gametithe.atlassian.net/browse/KAN-186) · [KAN-96 정산 단일 커밋](https://gametithe.atlassian.net/browse/KAN-96)

## 연결

1. 기존 Canvas와 GraphicRaycaster, EventSystem을 사용한다. 전체 화면 RectTransform에 `SettlementResultsPanel`을 붙이고 `Initialize(catalog, font)`에 무기 카탈로그와 한글 TMP 폰트를 넘긴다. 프로젝트에 TMP Essential Resources를 설치한다.
2. 호스트의 정산 호출이 반환한 결과를 `ShowCommit(commit)`에 넘긴다. 이미 저장된 결과를 다시 열 때에는 서비스 호출 없이 `ShowReceipt(receipt)`에 영수증을 넘긴다.
3. 확정 영수증을 표시하는 상태에서 로비 버튼을 누르면 패널이 닫히고 `ReturnToLobbyRequested(runId)`를 전달한다. 호스트가 해당 런의 나머지 자원 정리와 로비 화면 전환을 처리한다.

V2 영수증의 반입품 회수, 신규 획득, 상실, 대여 반납·종료, 정산 코인, 도감 신규 회수, 미반입 창고 무기와 기존 코인 보존을 표시한다. 같은 원형 무기는 화면에서 수량으로 묶고, 기존 자산 수치는 영수증의 값을 사용한다.

- 경합이 있으면 저장된 최초 결과와 이미 확정됐다는 안내를 표시한다.
- 저장 거절이나 데이터 부재는 안내만 표시한다. 이때 완료 동작은 제공하지 않으며 호스트가 저장 상태를 처리한다. 화면 자체에서 재시도나 정산 승인, 지급을 호출하지 않는다.
- V1은 영수증에 저장된 회수·획득 합계, 상실·대여 종료 건수와 코인만 표시한다. 상세 형식이 없는 기록은 알려진 종료 사유와 상세 내역이 없다는 안내를 표시한다.

## 재현

- 소유 무기를 반입하고 탐험 무기를 얻은 뒤 성공 귀환한다. 이번 정산으로 반입품 회수, 신규 획득, 미회수 반입품 상실, 코인 확정과 도감 새 회수가 각각 반영되는 것을 확인한다.
- 사망하거나 시간을 초과한다. 이번 탐험의 무기·코인 상실과 대여 종료가 보이고, 기존 확정 코인과 미반입 창고 무기 보존이 표시되는지 확인한다.
- 같은 런의 영수증을 다시 열거나 경쟁 결과를 받는다. 같은 세부 내용이 나타나고 저장 리비전이 증가하지 않아야 한다.
- 저장소가 없거나 정산 저장이 거절되면 세부 내역과 로비 버튼 대신 안내 문구를 확인한다.

Unity Test Runner의 EditMode에서 `ProjectWeapon.SettlementUI.Tests`를 실행한다. 실제 저장과 정산, 경합, 기존 영수증, 미확정 안내 및 호스트 복귀 통지를 검증한다.

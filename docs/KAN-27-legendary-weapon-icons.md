# KAN-27 전설 무기 3종 픽셀 아이콘

`Assets/ProjectWeapon/Art/LegendaryWeaponIcons/`에 원본 32×32px 투명 Sprite Single을 둔다. 32 PPU와 Point 필터를 사용한다. 우하단 금색 왕관이 전설 등급을 표시한다. 원본은 `art-source/Export-LegendaryWeaponIcons.ps1`로 재생성하며 외부 이미지를 사용하지 않는다. [KAN-27](https://gametithe.atlassian.net/browse/KAN-27) · [KAN-21](https://gametithe.atlassian.net/browse/KAN-21) · [KAN-22](https://gametithe.atlassian.net/browse/KAN-22)

| 무기 | Sprite | 형태 |
| --- | --- | --- |
| 천벌의 검 | `HeavensWrathSword` | 백금 검날과 십자 빛, 날개형 가드 |
| 종말의 낫 | `DoomScythe` | 붉은 이중 날과 낫 자루 위 부서진 초승달 |
| 창세의 활 | `GenesisBow` | 별 조각을 건 양쪽 활대와 청금색 중심 |

UI에서는 원본 종횡비를 유지하고 24×24px 이상으로 표시한다.

# KAN-98 폐성 보스 단일 충격파

[KAN-98](https://gametithe.atlassian.net/browse/KAN-98) · [KAN-86](https://gametithe.atlassian.net/browse/KAN-86)

## 실제 폐성 씬

`Assets/Scenes/ZoneOneGreybox/ZoneOneGreybox.unity` 북서쪽 방의 `(1.5, 6.5)`에 `AbandonedCastleBoss.prefab`을 배치했다. 시작 지점 `(3.5, 2.5)`에서 중앙 벽 남쪽을 돌아 귀환 지점으로 가면 보스 탐지 범위에 진입하지 않는다. 보스를 피해 기존 근접·원거리 경비와 상자 경로로 진행하고 귀환할 수 있다.

보스는 시야가 트인 2.0 월드 단위 안의 플레이어를 감지한다. 예고를 시작한 중심을 고정해 반경 1.6 원을 그리고, 예고 0.9초 후 한 번 판정한다. 피해 24, 회복 1.5초, 체력 90은 검증 가안이다. 피격 시 붉게 점멸하고 처치되면 회색이 된다. 시각 확인에는 기존 Guard 픽셀 스프라이트를 재사용했다.

`ZoneOneEncounter`의 자동공격과 낡은 검 수동 스킬은 보스를 시야 내 표적으로 취급한다. 단검 연타는 처음 선택한 보스 ID를 유지한다. `ShockwaveResolved`의 예정 타격 시각으로 다른 적 공격과 정렬해 기존 플레이어 피해 및 귀환 취소·사망 판정에 전달한다. 늦은 프레임에서 마감 전에 예정됐던 타격은 예정 시각으로 처리하고, 마감과 같거나 이후에 판정할 공격 예고는 시작하지 않는다. 이미 결과가 확정된 런은 대기 중 공격을 정리한다.

보스 처치는 대기 공격을 취소하고 `Defeated`에 런 ID, 보스 ID, 처치 확정 시각을 한 번 전달한다. 구역 해금과 귀환 정산은 기존 진행 서비스 범위다.

## 재현

1. `ZoneOneGreybox`를 Play한다. 시작 지점에서 좌측 북쪽 방의 `(2.5, 6.5)` 부근으로 가면 큰 보라색 보스가 원을 그린다. 원이 사라지기 전에 벗어나거나 회피한다. 낡은 검은 접근하면 자동으로 공격한다.
2. 우회 확인은 시작 지점에서 중앙 벽 남쪽으로 돌아 파란 귀환 지점에 접근한다. 원거리 경비를 먼저 처리한 뒤 `E`를 눌러 3초 채널을 완료한다. 성공 시 보스의 체력은 90이며 처치 이벤트는 0회다.
3. `BossEncounterTests`는 씬에 놓인 프리팹과 실제 자동·수동 공격, 단검 연타, 늦게 관측한 마감 경계를 검증한다. `ZoneOneGreyboxTests`는 실제 2D 이동 경로와 보스 생존 상태의 3초 귀환을 확인한다. `BossShockwaveTests`는 예고 반경과 고정 중심, 피격·처치 반응의 프리팹 계약을 확인한다.

```powershell
unity test . --mode PlayMode --output "$env:TEMP/KAN-98-zone-one-playmode.xml" --timeout 240
```
